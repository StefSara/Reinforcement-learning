# Reinforcement-learning
Jupyter notebooks implementing RL algorithms (Q-learning, value iteration, bandits) on Blackjack, CartPole, Maze, and Multi-Armed Bandit tasks

# fit

Jupyter notebooks implementing reinforcement learning algorithms (Q-learning, value iteration, bandits) on classic RL tasks.

## Contents

- **blackjack.ipynb** — Q-learning agent playing Blackjack, including a more realistic Level 1/Level 2 rule variant.
- **Cart_pole.ipynb** — Q-learning with state discretization on the classic CartPole balancing task.
- **maze.ipynb** — Value iteration / Q-learning agent navigating a grid maze with teleport cells.
- **multiarmBandit.ipynb** — Greedy, epsilon-greedy, and non-stationary multi-armed bandit algorithms compared via cumulative reward.

## Usage

Open any notebook in Jupyter and run all cells:

```bash
jupyter notebook
```
